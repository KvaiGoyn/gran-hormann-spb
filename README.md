# ГРАНЬ · Ворота и двери Hörmann

Исходный код многостраничного сайта офиса Санкт-Петербурга: каталог, страницы продукции, интерактивный 3D, калькулятор и формы заявок.

## Стек

- Интерфейс: HTML, CSS, JavaScript, Three.js.
- Сборка: Vite. Серверный runtime и endpoint заявок: Vinext + Cloudflare Workers.
- Хранилище заявок: Cloudflare D1 (SQLite), миграции Drizzle.
- Экспорт вёрстки для будущей интеграции с 1С-Битрикс: `npm run export:bitrix`.

## Локальный запуск

Нужны Node.js 22.13+ и npm. Production preview с локальной базой:

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_robust_toro.sql
npm start -- --port 4173
```

Первую миграцию выполнить один раз. Локальная база хранится в `.wrangler/state`. Для разработки: `npm run dev -- --port 5173`.

## Калькулятор и заявки

Демонстрационные тарифы заданы в `data/tariffs.json` и не являются прайсом Hörmann. Сервер повторно рассчитывает сумму выбранной комплектации. POST `/api/leads` проверяет запрос и сохраняет заявку в D1. Публичного API чтения заявок нет.

## 1С-Битрикс

`npm run export:bitrix` выгружает PHP-шаблон и страницы в `release/bitrix`. Шаблон лежит в `bitrix/templates/gran`, а его внутренние URL используют `/bitrix/templates/gran/`. Это каркас вёрстки: обработчик заявок в экспортированном пакете отвечает 503 до интеграции с формами и хранилищем установленного Битрикс.

## Материалы

Источники изображений перечислены в `ASSETS.md`. Архитектурный первый экран создан для проекта; локальный MP4 — беззвучная анимация архитектурных изображений. Перед публичным коммерческим использованием материалов и логотипа Hörmann проверьте права. Имя «ГРАНЬ» рабочее. Демонстрационные тарифы и сведения о контактах нужно заменить перед коммерческим запуском.

Лицензия на код проекта пока не задана; права на изображения производителя могут отличаться от лицензии кода.
