# ГРАНЬ · сайт офиса в Санкт-Петербурге

Цель: отдельный бренд офиса с продукцией Hörmann, архитектурным дизайном, видео, 3D, отдельными страницами, калькулятором и приёмом заявок. Рабочее название — ГРАНЬ. Синий/жёлтый близки к Hörmann. Главный референс — hoermann.ru. 1С-Битрикс подключается позже.

## Решения и границы
- Главная; каталог; 6 страниц направлений; калькулятор; о компании; сервис; контакты; политика обработки заявок; 404.
- Пользователь разрешил придумать тарифы. Калькулятор использует явные демонстрационные тарифы из data/tariffs.json, с разбивкой по полотну/цвету/поверхности/приводу/монтажу/доставке. Это не прайс Hörmann и не оферта.
- Реальный POST /api/leads сохраняет контакт и рассчитанную на сервере комплектацию в D1. Повтор запроса не создаёт дубль. Канал уведомлений и реальные реквизиты не предоставлены; не имитировать письмо или звонок.
- Локальный предпросмотр + приватная публикация Sites. Выгрузка шаблона для будущей интеграции Битрикс, без заявления о работающей CMS.
- Не добавлять неподтверждённые статус дилера, отзывы, адрес, телефон, гарантии или сроки.

## Приёмка и проверка
1. Все маршруты открываются напрямую с уникальными заголовками, неизвестный адрес возвращает 404 — HTTP smoke + браузерные переходы.
2. Выбор параметров меняет итог и разбивку, ошибки размеров блокируют расчёт — unit tests + браузер.
3. Заявка отправляется и существует в базе; повтор не дублирует, неверные поля/чужой origin отклонены — API tests + реальная отправка из браузера и чтение БД.
4. Десктоп/мобильный экран без горизонтального скролла, навигация и формы работают — фактический браузер.
5. 3D открывает ворота, меняет цвет, загружается лениво; reduced-motion учтён — браузер и тест траектории.
6. Production build и пакет для Битрикс собираются — npm run build / export:bitrix. PHP-интеграция не проверяется без Битрикс/PHP.
